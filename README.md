## Загрузка через сайт GitHub (без терминала)
1. Войдите в https://github.com/new и создайте **публичный** репозиторий `filtron-invest` (или используйте существующий).
2. Распакуйте ZIP и откройте папку, где лежит `index.html`.
3. В GitHub откройте репозиторий → **Add file → Upload files**. Загрузите **все файлы из папки**, а не ZIP.
4. Нажмите **Commit changes**. Если файлы с теми же названиями уже есть, загрузите их вместо старых.
5. Откройте **Settings → Pages → Build and deployment**: выберите `Deploy from a branch`, `main`, `/(root)` → **Save**.
6. Сайт появится по адресу `https://ВАШ_ЛОГИН.github.io/filtron-invest/`.
7. После обновления нажмите обновление страницы в браузере; если видите старую версию, откройте ссылку в приватной вкладке.

## Как проверить калькулятор
Откройте сайт в обычном браузере (Safari, Chrome), не во встроенном предпросмотре файлов ChatGPT или PDF-просмотрщике. Перейдите в «Экономика». По умолчанию — 1 500 MAU × 70% × 10 оплаченных суток = 10 500 суток и ~894 059 ₽ валовых платежей. При движении любого ползунка **все показатели справа меняются сразу**. Кнопка «Сбросить» возвращает параметры к исходным.

Файл `index.html` автономен в части оформления, логотипа и интерактивности. PDF и Excel остаются отдельными файлами; для работы кнопок скачивания загружайте их вместе с HTML в корень репозитория.

**Внимание:** GitHub Pages публикует сайт и находящиеся в репозитории PDF/Excel в открытый доступ. Не размещайте конфиденциальные документы в публичном репозитории.
