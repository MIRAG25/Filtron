# ФИЛЬТРОН — GitHub Pages / полный инвесторский пакет

## Как опубликовать (без программиста)

1. Распакуйте ZIP. **Не загружайте ZIP целиком** в репозиторий.
2. Откройте ваш репозиторий `Filtron` на GitHub (например: https://github.com/MIRAG25/Filtron ).
3. Перейдите в корневую папку репозитория. Если там есть старые `index.html`, `presentation.pdf`, `memorandum.pdf`, `finance.xlsx`, замените их одноимёнными файлами этого пакета.
4. Выберите **Add file → Upload files** и загрузите **все файлы из распакованной папки**. Файл `index.html` должен находиться именно в корне, а не во вложенной папке.
5. Нажмите **Commit changes**. В разделе **Settings → Pages** должно быть `Deploy from a branch` → `main` → `/(root)`.
6. Откройте сайт `https://mirag25.github.io/Filtron/` (если ваш репозиторий называется `Filtron`; регистр пути имеет значение).
7. Если видна старая версия, обновите страницу / откройте в приватной вкладке.

Сайт не требует отдельного VPS и работает на GitHub Pages (статический HTML + локальные файлы). Логотип встроен в `index.html`, поэтому не исчезает при открытии одного файла. `radar.png` также включён для документов.

## Содержимое

- `index.html` — главный опубликованный сайт (динамический калькулятор и календарь).
- `calculator.html` — расширенный интерактивный расчёт SaaS и FILTRON GOODS.
- `presentation.pdf` — актуальная презентация для инвестора, 18 слайдов.
- `strategy.pdf` — стратегия развития 2027–2028, 24 страницы.
- `memorandum.pdf` — отдельный инвестиционный меморандум, 8 страниц.
- `finance.xlsx` — Excel-модель с формулами (SaaS, сценарии, GOODS).
- `radar.png` — прозрачная эмблема.
- `presentation_source.html`, `memorandum_source.html` — редактируемые исходники PDF; не обязательны для GitHub Pages.

## Единые допущения

- Бюджет MVP: 250 000 ₽; транши 85 000 + 55 000 + 55 000 + 55 000 ₽.
- База 250 / 375 / 500 MAU за первые три месяца; целевой масштаб 1 500 MAU.
- Доля платящих 85%, оплаченных суток на плательщика 24, условная выручка за сутки 85 ₽.
- Из оборота: 3% эквайринг, 6% условный налог, 9% реферальные выплаты; затраты 65 000 ₽/мес + 40 ₽/MAU. Реклама / дополнительные сотрудники в базовый расчёт не включены.
- Получаемые по модели результаты: +280 470 / +453 205 / +625 940 ₽ (250/375/500 MAU).
- Тарифы: 1 день 100 ₽, 2 дня 170 ₽, 7 дней 550 ₽, 14 дней 990 ₽ (гипотеза), 30 дней 1950 ₽. 85 ₽/сутки при 24 сутках НЕ гарантируется тарифами — требуется фактическая верификация.
- GOODS: отдельный пилот 134 150 ₽, отдельно от 250 000 ₽ MVP.
- Каникулы команды: 24 декабря 2026 — 5 января 2027 включительно. Целевой релиз 23 января 2027.
